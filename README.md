# simple-mestimators

Robust estimation of aligned 2D cryo-EM images, with real/Fourier IRLS,
ADMM-derived coupling, and recursive GMM reweighting.

## Install and test

From the project root, use the supplied lock file:

```bash
uv sync --group dev
uv run pytest -q
```

## Paper simulations

All scientific options belong in YAML. The simulation CLI accepts only the
configuration path, input/output paths, and saving switches. The old scientific
CLI switches (`--snr`, `--n-runs`, `--seed`, `--standardize`,
`--standardize-reference`, `--initialization-strategy`) are no longer accepted;
move these values into YAML.

* `configs/paper_simulations.yaml`: 1000 inliers + 300 misclassified projections,
  five SNRs, ten realizations per SNR, and no residual rotations.
* `configs/paper_uncontaminated.yaml`: identical settings with 1000 inliers and
  zero outliers. Compare its methods against its own sample mean.

Both files specify lambda=1, the same automatic beta multiplier for CC, GMM-CC,
and the real ADMM branch, and Tagare eps=1e-8. These are the requested new
settings, not a reproduction of the old paper simulations with lambda=0.2.
The contaminated and clean configurations are deliberately complete independent
files; keep shared estimator settings synchronized if you edit them.

Relative paths in YAML are resolved beside that YAML; relative CLI paths are
resolved from the working directory. YAML input paths may be null when supplied
on the command line. The output directory must be new or empty.

Example batch (run at the project root):

```bash
uv run bash run_tilt_simulations.sh \
  --config configs/paper_simulations.yaml \
  --results-dir results/paper-v2 \
  --data-dir /path/to/angular_projections \
  --structure ribosome --tilt 10 --tilt 50
```

The script only selects files. SNRs, repetitions, estimator options, and random
seeds are never overridden by the script. Input names follow
`STRUCTURE/image_tilt_ANGLE.mrc`. Without explicit selections it retains the
original batch: three structures and outlier tilt files 10 through 90 degrees.

Run the uncontaminated control once per chosen inlier projection, not once per
outlier tilt:

```bash
uv run python -m scripts.experiments.run_simulation \
  --config configs/paper_uncontaminated.yaml \
  --results results/control/ribosome \
  --reference-image-path /path/to/angular_projections/ribosome/image_tilt_0.mrc
```

### YAML layout

* `data`: `reference_image_path`, `misclassified_path`; CLI paths override them.
* `output`: `save_weights`, `save_estimates`, `save_labels`.
* `simulation`: `snrs`, `n_runs`.
* `generation`: image counts, rotation/shift bounds, `standardize_reference`.
* `preprocessing`: `standardize`, `mask_radius`.
* `experiment`: `seed`, `initialization_strategy`, `methods`.

Small legacy YAMLs still receive historical defaults for omitted settings.
Use the complete paper YAMLs to avoid implicit experimental choices. Legacy
`mask.radius` is supported, but cannot coexist with `preprocessing.mask_radius`.
Unknown simulation sections/settings and unknown IRLS/ADMM options are rejected.

`standardize_reference: true` divides the clean inlier by its standard deviation
without subtracting its mean, and scales outlier projections by the same factor.
`standardize: none` disables additional per-image standardization. Gaussian noise
uses the unmasked clean inlier variance and is added before masking. No CTF is
generated by this simulation pipeline.

`mask_radius: null` resolves to `min(h//2, w//2)` and is saved numerically. This
corrects the old automatic radius on rectangular images; square-image radii
are unchanged. All residual rotation bounds are null in the supplied configs,
avoiding interpolation altogether.

### Algorithm options and fixed conventions

IRLS `tol` measures `norm(next-reference)/(norm(reference)+eps)`; GMM reference
updates use the corresponding relative change with a floored denominator.
Distinct methods may use distinct tolerances. Fixed iteration caps are not a
claim of convergence; inspect diagnostics before the full campaign.

ADMM options `check_every`, `inner_initial_iter`, `inner_iter_increment`,
`adaptive_mu`, `mu_balance_ratio`, `mu_increase_factor`, and `mu_decrease_factor`
make the previous internal schedule explicit. Inner caps are
`min(inner_initial_iter + outer_index*inner_iter_increment, solver.max_iter)`.
They start at 5 and grow to 10 in the supplied configuration. Residual checks
occur every 5 outer updates, and now also on the final update if the cap is not
a multiple of 5. Warm-started inner estimates use the previous domain states.
The dual variable is unscaled, so changing mu does not rescale that variable.
The returned estimate is the average of the two states expressed in real space.

GMM `gmm_max_iter` and `gmm_tol` control sklearn fitting, separately from
recursive `max_iter` and `tol`. `reg_covar`, `n_init`, and `init_params` are
explicit and survive model recreation on every new solve. Means and mixture
weights use the supplied quantiles/mass when `initialize_params: true`;
`init_params` supplies the remaining initialization, including covariance.
The method always uses two full-covariance components, warm start within the
recursion, and monotonic correction. A rejected fit returns the ordinary mean
and unit weights. Failure to reach sklearn's tolerance is recorded but does not
add a new rejection rule.

Fourier data use `rfft2` with `norm="ortho"`. Complex residual variances include
both real and imaginary parts, with sample ddof=1 for batches larger than one.
Empirical variances are fixed within each fit. Standalone methods have no prior;
ADMM supplies quadratic coupling through its inner calls. Returned weights are
the weights used in the final update, evaluated at the preceding reference;
they are not recomputed afterwards.

## Saved diagnostics

Existing estimates, weight arrays, and estimator-first directories are preserved.
`run.json` retains `dataset_seed` and adds `diagnostics` for fitted methods:

* iteration count, stopping reason, convergence, and last relative change;
* GMM fallback flag/reasons, final attempted component parameters, normalized
  separation, selected component mass, and sklearn fitting convergence;
* ADMM final residuals/thresholds, final mu, residual-evaluation mu, disagreement
  between returned states, and last inner-solver diagnostics;
* resolved estimator settings, including the numeric automatic beta.

GMM array diagnostics still describe the attempted model when it is rejected;
the actual saved particle weights are then the fallback unit weights. The
scalar diagnostics make this distinction explicit. Only the last attempted
GMM fit is summarized, not the complete iteration history.

Root `config.json` includes runtime dependency versions and a SHA-256 fingerprint
of project Python sources. Input paths, realized dataset seeds, and the actual
mask are retained as before. Source hashing is computed once per campaign.
Scientific reproducibility still requires retaining the input projections and
this source/configuration version. The readers tolerate the extra JSON fields.

The stored-dataset CLI keeps its existing override interface; these simulation
CLI changes do not remove options from `run_estimation`.
